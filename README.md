# Twitter (personal client)

Native SwiftUI client with a Bluesky-style layout: swipeable feed tabs, bottom bar, floating compose button.
Feeds are chosen in Settings (profile tab > Choose feeds):

- **Twitter: For You** and **Twitter: Following** (X's own timelines)
- **Bluesky: Following** plus any custom feeds you've saved on Bluesky
- **Combined**: Twitter Following + Bluesky Following merged by time

## Accounts
- **Twitter:** sign in on the real login page inside the app (Settings > Connect). Requests go from your phone via a hidden web view that listens to the timeline responses X's own page fetches.
- **Bluesky:** handle + an **app password** (Bluesky: Settings > Privacy and security > App passwords).

## Get the IPA
Push to `main` (or run *Build IPA* in Actions). Download `Twitter.ipa` from **Releases**
(`/releases/latest/download/Twitter.ipa`). It's unsigned; LiveContainer/AltStore/Sideloadly sign it.
A source file for Feather-style apps is in `source.json`.

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`.

## Layout
- `TwitterApp.swift`: app, tabs, home pager, post rows
- `SettingsViews.swift`: accounts, login sheets, feed picker
- `Feeds.swift`: feed definitions, persistence, loading/merging
- `XWebSource.swift`: hidden-webview X transport (tab switching, paging)
- `XTimelineParser.swift`: X JSON to `Post`
- `BlueskyClient.swift`: AT Protocol client (app-password session)
- `XAuth.swift`, `Secrets.swift`, `Post.swift`
