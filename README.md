# Twitter (personal client)

Native SwiftUI home-timeline client with a Twitter look. Step one of a combined Twitter + Bluesky feed.
Sign in happens on the real login page inside the app; requests go straight from your phone.

## Get the IPA
1. Push this repo to GitHub (private is fine).
2. **Actions > Build IPA** runs on every push to `main` (or hit *Run workflow*).
3. Download `Twitter.ipa` from the **Releases** page (or the run's artifacts).
4. The IPA is **unsigned**. Install it with LiveContainer, AltStore, Sideloadly, or TrollStore. They sign it for you.

The project file is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`, so there's no `.xcodeproj` to maintain.
To work locally: `brew install xcodegen && xcodegen generate && open TwitterApp.xcodeproj`.

## Transports (menu: top right)
- **Webview (default):** hidden web view loads the home page and reads the timeline X's own JS fetches. Most resilient.
- **Direct:** calls the private GraphQL API itself. Lighter, but may need tuning if X changes things.

## Status
First draft, never run against live X when written. Expect to fix parsing/headers from the first real responses. See `Sources/XClient.swift` and `Sources/XWebViewTransport.swift`.

## Layout
- `Sources/TwitterApp.swift`: app entry + themed timeline UI
- `Sources/XAuth.swift`: webview login, cookie capture, credential storage
- `Sources/XClient.swift`: direct API client + timeline parser
- `Sources/XWebViewTransport.swift`: webview capture transport
- `Sources/Post.swift`: network-agnostic `Post` model + `FeedSource` protocol (Bluesky plugs in here later)
